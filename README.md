# Bibi üçün ad günü sayti 🌸
- `index.html` — saytın özü
- `assets/` — şəkillər və `music.mp3`

## GitHub Pages
1. Yeni repo yarat (məs. `bibi-ad-gunu`), bu qovluğun içindəkiləri yüklə (Add file → Upload files).
2. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
3. 1-2 dəqiqə sonra: https://istifadəçi-adın.github.io/bibi-ad-gunu/

Giriş tapmacasının cavabı: qardaş oğlu
