## GitHub Pages ilə yayımlamaq
1. GitHub-da yeni repo yarat (məs. `bibi-ad-gunu`).
2. Bu qovluğun içindəkiləri (index.html, assets, README.md) repoya yüklə: **Add file → Upload files**.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save**.
4. 1-2 dəqiqə sonra sayt `https://İSTİFADƏÇİ-ADIN.github.io/bibi-ad-gunu/` ünvanında açılacaq.
